# Lab 03: Transfer Learning with PyTorch and Model Improvement

Este proyecto implementa un sistema de reconocimiento biométrico utilizando Transfer Learning con la arquitectura ResNet18, logrando distinguir entre el rostro del estudiante (Mateo) y el fondo/otras personas.

Incluye técnicas avanzadas de:
- Fine-Tuning: Descongelamiento selectivo de capas profundas (layer4).

- Learning Rate Diferencial: Optimizadores ajustados para capas pre-entrenadas y nuevas.

- Threshold Tuning: Implementación de umbrales de confianza para evitar falsos positivos (Test 3).

- Despliegue con Streamlit: Interfaz web interactiva para pruebas en tiempo real.
